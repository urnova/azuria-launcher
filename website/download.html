Guide d'installation rapide
1
Téléchargez et lancez l'installateur

Cliquez sur le bouton vert ci-dessus pour télécharger AzuriaSetup.exe.

2
Écran Windows SmartScreen (Sécurité Windows)

Si Windows affiche un écran de protection "Windows a protégé votre ordinateur", cliquez simplement sur "Informations complémentaires" puis sur "Exécuter quand même".

3
Choisissez votre compte

Ouvrez le Launcher Azuria. Connectez-vous avec votre compte Microsoft ou entrez simplement un pseudo en mode Hors-Ligne gratuit.

4
Cliquez sur Jouer !

Le launcher prépare les composants NeoForge et lance le jeu directement sur le serveur Azuria V4.
