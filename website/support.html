Guide des Codes d'Erreur Launcher

Retrouvez la solution immédiate selon le code affiché par le launcher.

AZ-008 · RÉSOLU DANS LA V4.0.33

Crash au lancement du jeu (ModLauncher / Client Jar)

Le jeu se ferme juste après le clic sur "Jouer" ou génère un crash report NeoForge sans ouvrir la fenêtre Minecraft.

✅ Solution : Téléchargez le Launcher Azuria v4.0.33 sur notre page Télécharger. Cette version lance automatiquement l'installateur NeoForge pour générer le jar client. Pensez aussi à allouer au moins 4 Go de RAM dans les réglages du launcher.
AZ-001

Session Microsoft expirée

Votre jeton d'authentification a expiré auprès des serveurs Microsoft Xbox Live.

✅ Solution : Déconnectez votre compte en haut du launcher et reconnectez-vous avec votre compte Microsoft, ou basculez en mode Hors-Ligne.
AZ-002

Java 21 introuvable

Minecraft 1.21.1 et NeoForge requièrent un environnement Java 21 64-bit pour fonctionner.

✅ Solution : Le launcher télécharge automatiquement Java 21. Si le téléchargement échoue, installez OpenJDK 21 (Eclipse Temurin) et indiquez son chemin dans les paramètres.
AZ-003

Minecraft non possédé

Le compte Microsoft utilisé ne possède pas la licence Minecraft Java Edition.

✅ Solution : Pas de panique ! Utilisez le mode Hors-Ligne (Crack) inclus gratuitement dans le launcher pour créer votre personnage en quelques secondes.
AZ-004

NeoForge introuvable / Fichiers corrompus

Les fichiers du chargeur de mods NeoForge sont incomplets ou corrompus.

✅ Solution : Fermez le launcher, supprimez le dossier %APPDATA%\.azuria et relancez le launcher v4.0.33 pour une réinstallation propre.
AZ-005

Téléchargement échoué

La connexion au serveur de mods ou à GitHub a été interrompue.

✅ Solution : Vérifiez votre accès internet. Désactivez temporairement votre pare-feu / antivirus ou votre VPN, puis relancez le launcher.
AZ-006 & AZ-007

Extraction des mods échouée / Archive vide

L'archive des mods V4 n'a pas pu être extraite dans votre dossier de jeu.

✅ Solution : Vérifiez qu'il reste au moins 3 Go d'espace libre sur votre disque C: et redémarrez le PC avant de relancer le launcher.
AZ-999

Erreur inconnue

Une anomalie non répertoriée s'est produite lors de l'exécution.

✅ Solution : Consultez les logs dans %APPDATA%\.azuria\logs et ouvrez un ticket d'aide ou demandez à Evan AI.
